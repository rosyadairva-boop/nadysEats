# Nady'sEats

Nady'sEats merupakan website sederhana yang dibuat sebagai media informasi dan pemesanan makanan serta minuman. Website ini memiliki beberapa halaman yang dapat digunakan untuk melihat menu, melakukan reservasi, melihat informasi tentang Nady'sEats, dan mengisi data pesanan.

## Tujuan

Website Nady'sEats dibuat untuk menerapkan materi yang telah dipelajari dalam pembuatan website menggunakan HTML, CSS, dan JavaScript serta menerapkan hasil perancangan dari Figma ke dalam bentuk website.

## Fitur Website

Website Nady'sEats memiliki beberapa fitur, yaitu:

- Beranda
- Menu makanan dan minuman
- Kategori menu
- Menambahkan menu ke keranjang
- Reservasi meja
- Halaman Tentang Kami
- Halaman Pesanan
- Form pengisian data pemesan
- Konfirmasi pesanan

## Halaman Website

Website Nady'sEats terdiri dari beberapa halaman:

1. **Beranda**  
   Menampilkan informasi awal mengenai Nady'sEats, kategori makanan dan minuman, serta beberapa menu pilihan.

2. **Menu**  
   Menampilkan berbagai makanan dan minuman berdasarkan kategori, lengkap dengan gambar, deskripsi, harga, dan tombol keranjang.

3. **Reservasi**  
   Digunakan untuk mengisi data reservasi seperti nama, nomor telepon, tanggal, waktu, jumlah tamu, dan catatan.

4. **Tentang Kami**  
   Berisi informasi mengenai Nady'sEats dan keunggulan yang dimiliki.

5. **Pesanan**  
   Digunakan untuk mengisi data pemesan dan melakukan konfirmasi pesanan.

## Teknologi yang Digunakan

- Bootstrap Icons
